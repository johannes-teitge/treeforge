# Explorer Classic Admin Visual Alignment

Patch 073 gleicht den Explorer optisch an das Classic Admin Design an.

## Problem

Der Explorer war eine ältere Standalone-Seite und verwendete noch Creme/Braun-Farben.

## Fix

Am Ende von `explorer.css` werden die alten Variablen und Komponenten auf Admin-nahe Tokens gemappt.

## Hinweis

Der Explorer bleibt technisch vorerst standalone.

Später sollte er vollständig über `AdminLayout` laufen.
