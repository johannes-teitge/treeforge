# Explorer V2 Resizable Node Tree Panel

Patch 080 ergänzt eine zweite Resize-Schiene im Explorer V2.

## Verhalten

```text
Sidebar Pages/Workspaces ↔ Node Tree ↔ Editor
```

## Funktionen

- Node Tree Breite per Drag ändern
- Doppelklick auf Trennlinie klappt Node Tree ein
- gelbe Linie bleibt sichtbar
- Breite wird in localStorage gespeichert
- collapsed-Status wird in localStorage gespeichert

## Storage Keys

```text
tfv2.nodeTreeWidth
tfv2.nodeTreeCollapsed
```
