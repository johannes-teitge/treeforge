# Explorer V2 Collapsible Node Tree

Patch 075 ergänzt einklappbare Nodes im Explorer V2.

## Funktionen

- Nodes mit Kindern bekommen Toggle-Pfeil
- Nodes ohne Kinder bekommen Platzhalter
- Einzelne Branches einklappen
- Alle auf
- Alle zu
- Zustand pro Seite in localStorage

## Storage Key

```text
tfv2.collapsedNodes.<pageId>
```

## Betrifft nur V2

Explorer V1 bleibt unverändert.
