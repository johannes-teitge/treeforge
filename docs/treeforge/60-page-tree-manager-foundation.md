# Page Tree Manager Foundation

Patch 070 ergänzt eine echte Seitenverwaltung.

## Route

```text
/admin/pages/
```

## Speicher

```text
storage/pages/pages.json
```

## Funktionen

- Seitenbaum anzeigen
- Root-Seite anlegen
- Unterseite anlegen
- Seite bearbeiten
- Explorer öffnen
- Page Settings öffnen

## Noch offen

- Explorer wirklich auf `page` Parameter umstellen
- Page Settings wirklich auf `page` Parameter umstellen
- Drag & Drop Sortierung
- Löschen mit Kinderprüfung
- Slug ändern mit Redirect-Prüfung
