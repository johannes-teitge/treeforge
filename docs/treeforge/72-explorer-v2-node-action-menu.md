# Explorer V2 Node Action Menu

Patch 082 ersetzt die vielen Toolbar-Icons durch ein kompaktes Node-Menü.

## Neu

Rechts in jeder Node-Zeile:

```text
⋯
```

Menü:

```text
Kind hinzufügen
Bearbeiten
Kopieren
Als Referenz einfügen
Duplizieren
Verschieben
Löschen
```

## Vorteil

- ruhigeres UI
- mehr Platz im Node Tree
- Aktionen bleiben vorbereitet über `data-node-action`
