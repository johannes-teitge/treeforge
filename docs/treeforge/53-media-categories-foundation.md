# Media Categories Foundation

Patch 063 ergänzt erste Media-Kategorien.

## Datei

```text
storage/media/categories.json
```

## Standard-Kategorien

```text
Logos
Hero
Blog
Downloads
Social Media
```

## Media Manager

Links werden angezeigt:

```text
Alle Medien
Nicht einsortiert

```

Zusätzlich:

```text

Filter nach Kategorie
```
