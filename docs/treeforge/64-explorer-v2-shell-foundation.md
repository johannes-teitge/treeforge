# Explorer V2 Shell Foundation

Patch 074 baut Explorer V2 parallel zu Explorer V1 neu auf.

## Route

```text
/admin/explorer-v2/
```

## Features

- Pages links
- Workspaces links
- Archive vorbereitet
- Node Tree rechts
- Editor Panel rechts
- Tabs: Editor, Preview, Properties, JSON
- resizebare Sidebar
- Doppelklick auf Linie klappt Sidebar ein
- Sidebar-Breite und collapsed Status in localStorage

Explorer V1 bleibt unangetastet.
