# Media Edit Metadata

Patch 054 ergänzt die Bearbeitung von Medien-Metadaten.

## Route

```text
/admin/media/edit.php?id=...
```

## Felder

```text
Titel
Alt-Text
Caption
Beschreibung
Kategorie
Tags
Copyright
Fotograf / Quelle
Lizenz
Fokuspunkt X/Y
Featured
```

## Dateiinfos

Angezeigt werden:

```text
ID
Dateiname
Originalname
Pfad
MIME
Art
Größe
Maße
Erstellt
Geändert
Verwendungen
```

## SVG

SVG wird als Vektor erkannt.

Hinweis:

```text
SVG wird nicht in Presets gerendert.
Social Image Verhalten folgt den Media Settings.
```
