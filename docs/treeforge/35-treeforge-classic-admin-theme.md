# TreeForge Classic Admin Theme

Patch 045 stellt das Backend auf das TreeForge-Classic-Compact-Layout um.

## Ziel

Die Oberfläche orientiert sich stärker am alten teitge CMS:

- flache obere Hauptnavigation
- keine linke globale Sidebar
- helle Arbeitsfläche
- klare Panels
- kompakte Typografie
- weniger fette Schrift
- weniger Schatten
- mehr Werkzeug-Charakter

## Geänderte Bereiche

```text
Dashboard
Settings
Page Settings
Media
Admin Navigation
```

## Grundsatz

TreeForge soll sich im Backend wie eine Arbeitsoberfläche anfühlen, nicht wie eine Marketing-Website.

Die Innovation liegt im Node-System, in RootNode, Media, Storage, Templates und Site Packages.

Die Bedienoberfläche bleibt ruhig, klar und effizient.
